# 💰 Sistem Keuangan - Front-End UI Showcase

## 📌 Tentang Repositori Ini
Repositori ini berisi *showcase* (pameran) antarmuka pengguna (UI) untuk aplikasi **Sistem Keuangan**. 

*(Catatan: Repositori ini berfokus pada tampilan Front-End dan interaksi visual. Kode untuk logika backend, database, dan autentikasi tidak disertakan untuk tujuan demonstrasi desain).*

Tujuan repositori ini adalah untuk memamerkan kemampuan saya dalam merancang *dashboard* web yang modern, bersih, responsif, dan mudah digunakan.

## 🎨 Fitur Antarmuka
- **Sidebar Navigasi:** Menu samping yang rapi dengan ikon untuk Dashboard, Transaksi, Laporan, Pengguna, Pengaturan, dan Panduan.
- **Kartu Ringkasan (Summary Cards):** Menampilkan total pemasukan, total pengeluaran, dan saldo kas secara *real-time*.
- **Grafik Interaktif:** Visualisasi data pemasukan dan pengeluaran bulanan menggunakan *Bar Chart*.
- **Panel Notifikasi:** Peringatan otomatis (misalnya: "Saldo kas menipis") yang muncul secara dinamis.
- **Desain Responsif:** Tampilan yang menyesuaikan ukuran layar (desktop maupun *mobile*).
